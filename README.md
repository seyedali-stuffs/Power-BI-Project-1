# Power-BI-Project-1
به نام خدا
بالاخره اولین پروژه تحلیل داده‌ام با Power BI تموم شد! 🚀

از داده‌های ادونچر ورکس بین سال‌های 2020 تا 2022 استفاده کردم.

🔍 کارهایی که انجام دادم:

· پاک‌سازی و آماده‌سازی داده‌ها
· مدل‌سازی داده‌ها
· ساخت داشبورد تعاملی برای نمایش

🛠 ابزارها: Power BI, Power Query, DAX

سعی کردم تا حد ممکن گروه مشتریان رو برای بازاریابی بهتر مشخص کنم. همچنین یه تورم سالانه هم در نظر گرفتم و درامد رو نسبت به تورم بررسی کردم و البته کلی کار دیگه که می‌تونید ببینید🤌
